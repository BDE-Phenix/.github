# 🔥 BDE-Phenix

 Bienvenue sur l'organisation **BDE-Phenix** !

 BDE-Phenix est un projet développé par Alexis et YanisBleu, avec pour objectif de construire une application moderne, maintenable et évolutive pour répondre aux besoins de notre BDE.

 ## 👥 L'équipe

 Le projet est développé par :

- **Yanisbleu** - Front-end & Fix 🖥️\
   Responsable principalement de l'interface utilisateur, de l'expérience front-end et de la correction des bugs.
- **Alexis** - Back-end & Features ⚙️\
   Responsable principalement du développement back-end, de l'architecture serveur et de l'implémentation des nouvelles fonctionnalités.

 Nous travaillons ensemble pour faire évoluer le projet, corriger les problèmes et proposer une expérience toujours plus complète.

 ## 🛠️ Organisation du développement

 

 Nous nous répartissons principalement le travail de la manière suivante :

 | Domaine | Responsable |
| --- | --- |
| 🎨 Front-end | Yanisbleu |
| 🐛 Fix / Corrections | Yanisbleu |
| ⚙️ Back-end | Alexis |
| ✨ Features | Alexis |
| 🔄 Intégration | Équipe |

 Cette organisation reste flexible : nous pouvons intervenir sur les différentes parties du projet lorsque cela est nécessaire.

 ## 📂 Projets

Le projet utilise principalement :

 Svelte - Framework front-end
 TypeScript - Typage et développement
 CSS - Mise en forme et design de l'interface

 Les différents repositories de cette organisation contiennent les composants nécessaires au fonctionnement et au développement de BDE-Phenix.

 Chaque repository possède son propre README avec les informations nécessaires pour :

 - installer le projet ;
 - lancer le projet en local ;
 - contribuer ;
 - comprendre son architecture.


## 🤝 Contribution
Les contributions et suggestions sont les bienvenues.

Avant de proposer une modification :

Gardez un code propre et cohérent avec le projet.

- 🧹 un code propre et maintenable ;

- 🎨 une interface agréable et intuitive ;
- 🔒 une architecture fiable ;
